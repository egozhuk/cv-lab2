# cv-lab2

Ноутбук обучает детектор цифр в два этапа: сначала YOLOv8n обучается на датасете NumberDetection, затем дообучается на SVHN. После обучения модель оценивается на тестовой части SVHN и запускается на пользовательских фотографиях.

## Результаты на тестовой выборке SVHN

- Precision: 0.739
- Recall: 0.754
- mAP@0.5: **0.820**
- mAP@0.5:0.95: 0.400

## Данные

Датасет NumberDetection ожидается в `data/data/numberdetection/`, SVHN в `data/svhn_yolo/`. Для проверки на своих изображениях используйте папку `photos/my photos/`.

## Запуск

Откройте `lab2.ipynb` и выполните ячейки последовательно. Ноутбук использует Ultralytics YOLO, PyTorch, Pillow, PyYAML и matplotlib. Требуется заранее подготовить датасеты в формате YOLO.
